# i18n (다국어)

Code-first foundation. There are no Figma language frames yet.

## How it works

- **Locales:** `ko` is the source and the default. `en` is the second locale. 中文, 日本語 and ภาษาไทย are listed in the language menu as 준비 중 and cannot be selected yet.
- **Where the choice is stored:** the `ssumnation-locale` cookie, set by `setLocale()` in `lib/i18n/actions.ts`.
- **Rendering:** the root layout reads the cookie on every request. It sets `<html lang>` and wraps the app in `I18nProvider`, so the first render is already in the chosen language.
- **Messages:** they live in `src/lib/i18n/messages/{ko,en}.ts`.
  - `ko` defines the shape.
  - `en: Messages` must have every key; TypeScript and `translate.test.ts` enforce it.
- **Lookup:**
  - Client components: `const { t } = useI18n()`, then `t("nav.creators")` or `t("profile.fun", { name })`.
  - Server components: `const t = await getT()` from `lib/i18n/server`.
- **Missing translations:** a key missing in a locale falls back to Korean, and then to the key itself.

## Translated so far

The shared shell:

- Global header and profile menus
- Language menu and theme toggle
- Side menu, including the charge buttons
- Footer, except the legal entity lines

## Adding a screen

1. Add an area (for example `wallet: { ... }`) to `ko.ts`, and the same keys to `en.ts`.
2. Replace the literal strings with `t("wallet.key")`.
3. Keep policy numbers, legal text and user content out of the messages. Legal and terms text needs an approved translation (TBD).
