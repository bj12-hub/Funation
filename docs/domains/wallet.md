# Wallet Domain

```text
User
  ↓
Wallet
  ↓
Wallet Transaction
```

Wallet balance is server-authoritative.

Every balance-changing operation should be auditable and idempotent where applicable.

## 충전 환불 (code-first)

회원이 FN 충전내역 상세에서 환불을 요청하고, 운영자가 어드민 콘솔에서 승인 · 거절합니다. 환불 정책(기간 · 부분 사용 · 수수료)과 결제대행사 취소(원화 환불)는 TBD입니다.

- 승인하면 충전 FN이 보유 FN에서 회수되고, 그 변경이 지갑 기록으로 남습니다: FN Wallet에 `환불` 항목(−충전 FN)이 생기고 원래 충전 항목은 `환불완료`로 표시됩니다. 충전내역 CSV에는 `환불 상태` 열이 있습니다.
- 감사 로그에는 처리 메모와 함께 회수한 FN이 남습니다.
- 같은 충전에 다시 요청하면 기존 요청의 현재 상태(요청 · 승인 · 거절)를 돌려줍니다.
- 요청에는 요청한 회원과 그 계정의 시작 시점이 함께 저장됩니다. 탈퇴한 계정의 요청은 어드민에서 "탈퇴한 회원"으로 표시되고, 탈퇴 후 환불 요청 처리 방법이 TBD라 승인 · 거절할 수 없습니다.

## 회원 탈퇴 (2026-10-04 · 2026-10-05 결정)

회원 탈퇴는 남은 FN 소멸에 동의하고 비밀번호를 다시 입력하면 바로 처리됩니다. 크리에이터는 정산 대기 수익(정산 가능 + 정산 신청 중)에 대해서도 별도로 소멸 동의를 받습니다.

- 동의는 화면에 보여 준 금액에 대한 것이므로, 서버는 요청에 담긴 금액(남은 FN · 정산 대기 수익)이 현재 값과 같을 때만 처리합니다.
- 소멸된 FN · 정산 대기 수익과 탈퇴 시각은 탈퇴 기록으로 남습니다 (관리자 회원 상세에서 확인).
- 심사 대기 중이던 정산 신청은 "탈퇴 소멸"(`FORFEITED`) 상태로 바뀝니다. 반려가 아니라서 신청 가능 금액으로 돌아가지 않습니다.
- 비밀번호 시도 횟수 제한은 백엔드가 맡습니다. 소셜 로그인만 쓰는 계정은 그 로그인으로 다시 확인합니다(연동 TBD).
- 탈퇴 후에는 바로 새 계정으로 재가입할 수 있습니다. 이전 FN · 기록은 복구되지 않습니다.
- 재시도는 요청 id로 한 번만 처리됩니다.
- 기록 보관 기간은 TBD입니다.
