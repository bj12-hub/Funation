# Donation Domain

```text
Supporter
  ↓
Wallet
  ↓
Donation Order
  ↓
Donation Event
  ↓
Creator
```

Platform-specific behavior is handled through adapters.

```text
Donation Core
    ↓
PlatformAdapter
    ├── YouTube
    ├── FlexTV
    ├── SOOP
    └── CHZZK
```

## 퀘스트 후원 결과 (2026-10-04 결정)

- 퀘스트 후원은 보낼 때 성공 보상 금액 전부를 FN에서 차감해 보관한다.
- 결과를 정할 수 있는 사람 (위젯 설정의 결정 권한 표): 보낸 후원자는 항상(성공 · 실패), 크리에이터는 후원자가 "크리에이터 성공 결정"을 켠 경우에만(성공 · 실패). **취소**는 크리에이터만 언제든 할 수 있다.
- **성공**: 금액은 크리에이터에게 간다.
- **실패**: 후원한 FN을 후원자에게 **전액 환불**한다. 실패 금액 · 실패 패널티는 없다.
- **취소** (크리에이터): 실패와 같이 **전액 환불**한다. 취소 금액 · 취소 패널티는 없다. 상태 표기 "취소 · 환불".
- **제한 시간**: 지나도 자동으로 끝내지 않는다. 누군가 결과를 정할 때까지 진행 중으로 남고, 퀘스트 위젯에는 "시간 초과 · 결과 대기"로 보인다.
- 결과는 한 번만 정한다. 같은 결과를 다시 보내면 첫 결과를 그대로 돌려주고(재시도 안전), 다른 결과는 거절한다. 환불은 한 번만 일어난다.
- 기록: 결정 시각 · 결정한 쪽(크리에이터 / 후원자) · 환불 금액. 후원자 지갑에는 해당 후원이 "환불완료"가 되고 FN 내역에 환불 줄과 알림(실패 / 취소 문구)이 생긴다.

## 게임 당첨 (2026-10-04 결정)

룰렛 · 뽑기의 당첨은 **크리에이터 상품**(미션 · 굿즈 등)이고 FN으로 지급하지 않는다. 추첨은 서버가 하고, 결과는 방송 오버레이에 보인다.

### 룰렛 (구현)

- 크리에이터 설정(위젯 › 룰렛): 후원 받기 ON/OFF, 최소 참여 금액(1,000 FN 이상), 1인 하루 참여 가능 횟수(0 = 제한 없음), 항목 2~10개와 정수 확률(합 100%), 회전 시간, 자동 시작.
- 참여: 최소 참여 금액 이상 후원 1건 = 1회 참여(금액이 커도 1회). 일반 후원과 같은 Donation Core로 FN을 차감하고, 결과는 그 자리에서 서버가 추첨해 저장한다(시청자가 본 항목 · 확률 그대로). 결과는 룰렛이 돌아가 멈출 때까지 시청자 · 리모컨 어디에도 보이지 않는다.
- 진행: 채널마다 한 번에 하나씩 돈다. 자동 시작이 켜져 있으면 앞 순서가 끝나는 대로, 꺼져 있으면 리모컨 ▶ 시작으로 돈다. 일시정지는 자동 시작만 멈춘다. 결과는 몇 초 동안 오버레이에 보이고, 리모컨 ✓ 완료로 먼저 내릴 수 있다.
- 결과 자동 노출(펀페이 1009:355): 끄면 룰렛이 멈춘 뒤 "결과 공개 대기"로 남고, 리모컨 ✓ 결과 공개를 눌러야 결과가 보인다(다음 순서도 그때까지 기다린다). 후원 받기 · 자동 시작 · 결과 자동 노출은 리모컨 스위치와 위젯 설정이 같은 값이다. 위젯 화면 숨기기는 오버레이만 비우고 진행은 계속된다(뽑기도 같은 화면 숨기기).
- 시청자: 방송 방 룰렛 패널에서 항목 · 확률, 참여 조건, 남은 참여, 내 룰렛(대기 순서 · 결과 · 결과 번호 #RLT-…)을 본다. "꽝" 항목은 꽝으로 보인다.

### 뽑기 (구현)

- 크리에이터 설정은 기존 뽑기 후원 위젯(373:3675): 뽑기마다 가격, 당첨확률형(정수 % 합 100) 또는 상품소진형(재고 수량), 1인 횟수 한도, 기계 회전 시간, 알림 메시지 템플릿({닉네임} · {금액}), 스타일(캡슐 · 박스 · 크레딧).
- 시청자: 방송 방 후원 패널의 "뽑기"에서 켜진 뽑기를 골라 확률 또는 남은 수량을 보고, 확률 · 상품 안내 동의(필수) 후 그 뽑기 가격을 후원한다(같은 Donation Core). 1회 후원 = 1회 뽑기.
- 추첨: 결제 직후 서버가 정한다. 상품소진형은 그 자리에서 재고가 줄고, 모두 소진되면 참여를 받지 않는다. 결과는 뽑기 오버레이에서 기계가 멈출 때까지 보이지 않는다(채널마다 한 번에 하나, 순서대로 자동 재생).
- 크리에이터: 리모컨 뽑기 카드에서 실행 대기 · 결과를 보고 ✓ 완료(결과 일찍 내리기), 상품별 수령 처리(수령 완료 ↔ 미수령). 위젯 팝업의 당첨 내역과 미확인 개수도 실제 기록을 읽는다.
- 당첨 리스트 위젯(전광판): 산정 기간(오늘 · 7일 · 30일) 안의 당첨 상품(꽝 제외)을 상품 타입별로 흘려 보여 준다.

### 없앤 후원 유형 (2026-10-04 결정)

- 럭키박스: 후원 유형 · 럭키박스 위젯 · 크리에이터 랭킹의 럭키박스 탭 · 마이페이지 랭킹 노출 토글을 없앴다.
