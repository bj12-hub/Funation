# Donation Domain

```text
Supporter
  ↓
Wallet
  ↓
Donation Order
  ↓
Donation Event
  ↓
Creator
```

Platform-specific behavior is handled through adapters.

```text
Donation Core
    ↓
PlatformAdapter
    ├── YouTube
    ├── FlexTV
    └── SOOP
```

## 퀘스트 후원 결과 (2026-10-04 결정)

- 퀘스트 후원은 보낼 때 성공 보상 금액 전부를 FN에서 차감해 보관한다.
- 결과를 정할 수 있는 사람 (위젯 설정의 결정 권한 표): 보낸 후원자는 항상, 크리에이터는 후원자가 "크리에이터 성공 결정"을 켠 경우에만.
- **성공**: 금액은 크리에이터에게 간다.
- **실패**: 후원한 FN을 후원자에게 **전액 환불**한다. 실패 금액 · 실패 패널티는 없다.
- 결과는 한 번만 정한다. 같은 결과를 다시 보내면 첫 결과를 그대로 돌려주고(재시도 안전), 다른 결과는 거절한다. 환불은 한 번만 일어난다.
- 기록: 결정 시각 · 결정한 쪽(크리에이터 / 후원자) · 환불 금액. 후원자 지갑에는 해당 후원이 "환불완료"가 되고 FN 내역에 환불 줄이 생긴다.
- TBD: 제한 시간이 지나도 결정이 없을 때의 처리, 취소 금액 · 취소 패널티의 의미와 정산.
