# FlexTV 도우미 (레거시) 분석과 오버레이 테마 개편

2026-10-08 사용자가 레거시 "플렉스 도우미" 소스(`flextv-livehelper-main.zip`, 저장소에 넣지 않음)를 주고
"기존 버전들을 최근 트렌드에 맞게 디자인 재설정"을 요청했다. 이 문서는 분석 결과와 그에 따른 개편 계획이다.
레거시 코드 · 이미지 · 문구는 복사하지 않는다(구조와 기능 목록만 참고).

## 1. 레거시 구성

| 부분 | 내용 |
|---|---|
| 서버 | CodeIgniter 3 PHP API, Node socket.io 실시간 서버, Redis pub/sub, MariaDB |
| 흐름 | FlexTV 서버 → `POST /event/message` → Redis → socket.io 방(`{회원}_{위젯}`) → OBS 오버레이 `/pages/{위젯}/{32자 키}` |
| 화면 | jQuery 1.12 · Bootstrap 4 설정 페이지 24개, 오버레이 위젯 20여 개, CreateJS · Cocos · Unity 게임 |
| TTS | Google Wavenet · FlexTTS · Typecast (캐시 없음) |
| `solution-ui` | Next.js 13 리뉴얼 시작 흔적 (방송 도우미 / 매니저 도우미 / 앱스토어 메뉴, 기능 없음) |

보안: 레거시는 이벤트 수신에 인증이 없고(누구나 가짜 후원 알림 · TTS 가능), 앱 로그인 검증이 약하며, 키가 소스에
들어 있다. 이 서버 구조와 코드는 가져오지 않는다. 썸네이션은 서버 추첨, 키 재발급, 서명 검증을 이미 쓴다.

| 레거시 | 썸네이션 | 개편 |

| 엑셀 · 합동방송 · 배틀 · 팀 (엑셀 테마 15종) | 크루 방송 · 배틀 · 강탈 · 시나리오 | 테마 |

| 모바일 알림 · 목표 (`_m`) | 없음 | 세로 방송용 변형 신설 |
| 하트 · 꿀단지 | — | FlexTV 전용 아이템이라 제외 |
| 럭키카드 · 경마 | — | 제외 (럭키박스 제거 결정과 겹침) |

## 3. 레거시에서 피할 것 (설정 화면 UX)

- 1,000줄이 넘는 한 장짜리 폼 → 짧은 섹션
- 영어 animate.css 효과 이름 60여 개 → 한국어 효과 이름 몇 개 (`EFFECT_LABELS`, `OVERLAY_MOTIONS`)
- 오버레이와 따로 만든 미리보기 → 오버레이 컴포넌트를 그대로 그리는 미리보기
- 확인 없는 삭제, 저장되지 않는 정렬

## 4. 오버레이 테마 (2026-10-08 결정)

세 테마를 모든 오버레이에 제공하고, 채널 전체 테마 + 위젯별 선택으로 고른다.

| 키 | 이름 | 모양 |
|---|---|---|
| `BOLD` | 볼드 플랫 | 굵은 외곽선, 원색 블록, 블록 그림자, Archivo Black 숫자 |
| `PILL` | 미니멀 필 (기본) | 다이내믹 아일랜드식 어두운 알약, 절제된 숫자 |
| `GLASS` | 소프트 글래스 | 반투명 카드, 큰 라운드, 파스텔, Fredoka 숫자 |

- 토큰과 공통 요소: `apps/web/src/features/overlayTheme/overlayTheme.module.css` (`data-ov` 루트, `card` · `accentCard` · `chip` · `display` · `track`/`fill` · `enter[data-motion]`)
- 설정: `services/creator/overlayTheme*.ts` — 전체 테마 + 포인트 색상(없으면 테마 기본 색), 오버레이는 `overlayTheme(choice)`로 읽음
- OBS 브라우저 소스는 투명이라 배경 흐림(backdrop blur)이 효과가 없다. 글래스는 밝은 틴트 · 안쪽 하이라이트 · 그림자로 표현한다.
