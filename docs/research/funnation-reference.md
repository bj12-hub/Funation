# 참고 서비스 분석: funnation.co.kr (펀네이션)

- 조사일: 2026-09-29. 사용자 계정으로 로그인한 상태에서 **보기만** 했습니다. 후원·충전·설정 변경·글 작성 같은 동작은 하지 않았습니다.
- 성격: **외부 참고 자료**입니다. CLAUDE.md §2의 기준 문서(Figma → README → docs → 코드)에 속하지 않습니다.
  - 여기 적힌 기능과 수치는 **확정 제품 규칙이 아닙니다.** 채택하려면 제품 결정이 필요하고, 가능하면 Figma 디자인도 있어야 합니다.
  - 수수료·환불·정산 일정 같은 정책 값은 "참고 사례"로만 적었습니다. 우리 서비스의 값은 계속 **TBD**입니다(CLAUDE.md §14).
- 코드, 문구, 이미지, 약관 원문은 가져오지 않았습니다. 다른 이용자의 닉네임이나 개인정보도 기록하지 않았습니다.

범례: ✅ 우리도 있음 · 🟡 일부 있음/다르게 구현 · ❌ 없음

## 5. 우리에게 옮길 후보 (우선순위 제안)

**P1 — 우리 도메인의 빈칸과 바로 겹치는 것**
1. **크루(엑셀) 방송 시스템.** 크루 멤버, 멤버 지정 시그니처, 멤버별 순위, 점수판, 프리셋·회차, 방송 이력을 다룹니다. 우리 TBD인 "게임/크루 후원"과 대응하고, 후원 코어는 그대로 두고 멤버 귀속과 집계만 추가하면 됩니다(CLAUDE.md §10).
2. **후원자 정체성.** 후원용 별명, 익명, VIP 등급·글로벌 칭호·스토어 칭호 장착, 후원 알림 미리보기가 해당됩니다. 등급 기준 금액은 TBD로 둡니다.
3. **채널 만들기 = Creator 역할 부여 흐름.** 스스로 채널을 만드는 방식은 우리가 막 만든 역할 검사(`getCreatorSession`)의 빈칸을 채울 참고안입니다. 승인이 필요한지는 제품 결정 사항입니다.
4. **정산 인증 단계 체크리스트.** 본인인증 / 신분증 / 계좌 상태를 한눈에 보여 주는 방식입니다. OCR은 외부 제공자가 필요하므로 TBD입니다.
5. **캐시 환불 신청 흐름과 상품 구매 내역.** 환불 정책 자체는 TBD입니다.

**P2 — 새 서비스 영역**
- 쪽지(보관·스팸 신고 포함)
- 커뮤니티(전체 게시판 + 채널 커뮤니티)
- 이벤트(진행 중·예정·내 참여)
- 위젯 추가: 배너, 자막, 전광판, 엔딩 크레딧, 타이머, 이모지·레이어 효과
- 내 랭킹 화면

**P3 — 외부 연동이나 법무가 필요한 것**
- 외부 후원 플랫폼 실시간 연동, SMS 계좌후원 연결
- 다른 플랫폼 후원 내역 이관
- YouTube 영상 연동
- 캐릭터 보이스 판매(유료 상품)
- 테마 / 영어

## 6. 적용 원칙

- **디자인:** Figma가 기준이므로 새 화면은 디자인을 요청하거나, 기존 토큰과 컴포넌트로 만든 뒤 "디자인 없음"으로 표시합니다.
- **정책 값:** 위 4장의 값은 코드에 넣지 않습니다. 필요하면 서버 목업 정책에 넣고 TBD 주석을 답니다.
- **금액이 움직이는 기능:** 보이스 구매, 캐시 환불, 크루 정산처럼 금액이 오가는 기능은 기존 원칙을 그대로 따릅니다(서버 금액 계산, Idempotency-Key, 테스트).
- **외부 연동:** CLAUDE.md §9의 PlatformAdapter 패턴을 씁니다. 확정 플랫폼이 아닌 곳(예: 투네이션)과의 연동은 제품 결정이 먼저 필요합니다.
