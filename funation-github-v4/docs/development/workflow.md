# Development Workflow

1. Confirm requirement.
2. Locate Figma frame.
3. Identify role.
4. Identify route.
5. Identify state.
6. Identify domain.
7. Identify platform if applicable.
8. Inspect existing code.
9. Implement smallest coherent change.
10. Test.
11. Create PR.

UI flow:

```text
Figma
 ↓
Next.js Route
 ↓
Feature
 ↓
Component
 ↓
API Service
```
